# Возможности источника и границы первой версии

Дата анализа: 26 октября 2026. Официальные сайты документации, лицензии и тарифов недоступны из текущей облачной среды: HTTPS-прокси вернул 403. Таблица фиксирует реализацию, а не подтверждённый тариф или юридическое разрешение.

| Функция | Реализация | Доступ и ограничения |
|---|---|---|
| Поиск организаций | `GET /3.0/items`, type=branch | API-ключ; live-проверка ожидает ключа |
| Регионы | `GET /2.0/region/search` | Доступ проверяется при выборе; не точная граница района |
| Рубрики | `GET /2.0/catalog/rubric/search` | Регион, точное название; неоднозначность останавливает задачу |
| Названия, адреса, координаты | Нормализация реально возвращённых полей | Диагностика отдельных fields; отсутствующее значение — unknown |
| Контакты | `items.contact_groups`, классификация по типу/домену | Отдельное разрешение; отсутствие поля не доказывает отсутствие контакта |
| Наличие сайта/рейтинга/отзывов/фотографий | Нативные параметры, если диагностический запрос успешен | Безопасная передача из AND-групп; в OR нужны доступные значения |
| Рейтинг и число отзывов | `items.reviews` при наблюдаемом ответе | Числовые диапазоны только с доступными полями; текстов отзывов нет |
| Расписание и сеть | Поля модели/отображение/экспорт | Не все поля доступны ключу; временной фильтр не реализован |
| AND/OR, unknown | Трёхзначная логика, вложенные группы | Неизвестность разрешается только на итоговом уровне |
| История, шаблоны, пауза/возобновление | SQLite, курсор страницы, один worker | После сбоя нужна ручная команда продолжения |
| CSV/XLSX/JSON | Конструктор колонок и выбранные строки | Demo свободно; live только с правом экспорта |
| Массовое хранение | По явной настройке прав договора | Настройка не заменяет разрешение поставщика; срок задаёт пользователь |
| Тарифы и квоты | Не зафиксированы | Проверить актуальные в кабинете 2ГИС; настраивать частоту по договору |
| Проверка доступности сайтов | Недоступна | Произвольные URL сервер не запрашивает |
| Полигоны, границы районов, исключаемые зоны | Недоступны | Не заменяются приблизительным поиском |
| Дата открытия, фильтры по рабочему времени, каталог подкатегорий | Недоступны | Расширение через DataProvider и матрицу возможностей |
| Сравнение запусков, CRM, командный режим | Недоступны | Отдельное дальнейшее развитие |

Официальные ссылки для проверки владельцем ключа:

- https://docs.2gis.com/ru/api/search/places/overview
- https://docs.2gis.com/ru/api/search/places/reference/3.0/items
- https://docs.2gis.com/ru/api/search/categories/overview
- https://docs.2gis.com/ru/api/search/regions/overview
- https://law.2gis.ru/api-rules/
- https://dev.2gis.com/

Реальная live-выдача не проверялась, тариф не устанавливался. Моки HTTP-транспорта используются только тестами; рабочий провайдер никогда не возвращает тестовые организации.
